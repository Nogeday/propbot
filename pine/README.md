# pine/

TradingView'daki **güncel** strateji script'lerini buraya `.pine` uzantısıyla koy (kaynak her zaman TradingView'dır):

- `master_portfolio.pine` — NY ORB + Asian Sweep birleşik script
- `ny_open_fvg_strategy.pine`
- `asian_sweep_reversal_strategy.pine`
- `bb_kc_rsi2_mean_reversion.pine`
- `ict_silver_bullet.pine`

Kopyalama: TradingView → Pine Editor → script'i aç → `Ctrl+A`, `Ctrl+C` → Metin Düzenleyici → `Ctrl+V` → bu klasöre kaydet.
Dosya adları snake_case ve `.pine` uzantılı. TradingView'da olmayan bir strateji varsa listeden çıkar.
Faz 0 bu dosyaları düzeltir; sonrasında strateji mantığının referansı bunlardır.
